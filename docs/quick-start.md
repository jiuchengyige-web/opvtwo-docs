# 快速开始

## 1. 准备服务器

建议使用 Linux x86_64 服务器，准备 root 权限，并预留 1GB 以上内存。安装前请备份服务器上的重要数据。

## 2. 获取官方安装入口

安装命令会随版本调整，请前往 [OPVTWO 官网](https://home.opvtwo.com/) 获取当前版本的正确安装方式。

> 不要使用来源不明的旧脚本、修改包或第三方转载版本。

## 3. 完成授权与基础配置

安装完成后，按提示创建管理后台并完成正版授权。随后建议按以下顺序配置：

1. 修改管理员密码和安全设置。
2. 添加 OP 或 V2 节点。
3. 创建套餐与线路分类。
4. 配置用户注册、订阅和到期规则。
5. 配置支付接口、商城和发卡功能。
6. 小范围测试下单、开通、续费和过期踢线流程。

OVERVIEW

产品概览

OPVTWO 流控系统是一套面向流控运营场景的管理系统。它将节点、用户、订阅、线路、代理、商城、订单和授权放在同一套后台中，适合需要统一管理运营数据的团队。

双内核管理OP 与 V2 节点集中接入。
用户中心套餐、流量、冻结与副号。
代理体系五级分销与固定成本模式。
商业运营发卡商城、支付与订单。

说明：本 GitHub 仓库只提供产品文档和界面展示，不包含核心程序、数据库或授权接口。

MODULES

功能模块

01

节点与订阅

集中管理 OP、V2 节点，查看在线人数、用户流量与节点状态，并为用户提供订阅模式配置。

02

用户与套餐

管理账号状态、到期时间、剩余流量、冻结、副号、签到、注册赠送和套餐升级。

03

线路管理

支持线路分类、排序、推送线路与节点安装信息维护，减少手工重复配置。

04

代理与分销

提供百分比分销和固定拿货成本两种模式，支持下级开通、续费、余额与价格限制。

05

商城与发卡

自营商城与代理店铺共用订单流程，支持卡密、在线支付、未支付订单清理与退款处理。

06

运营与安全

包含优惠活动、广告域名拦截、授权校验、过期踢线及后台安全设置。

SECURITY

安全说明

  • 不要从非官方来源下载安装包或使用来源不明的修改版本。
  • 后台管理员密码、数据库密码、支付密钥和授权接口必须独立设置并妥善保存。
  • 开放端口应遵循最小权限原则，后台建议限制访问来源并启用 HTTPS。
  • 升级、恢复数据库或修改节点前，先完成数据库与配置文件备份。
  • 公开截图或文档时，不要暴露客户账号、订单、密钥、服务器 IP 和接口令牌。
